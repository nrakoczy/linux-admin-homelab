# Linux & Network Administration Homelab

Repozytorium dokumentujące moją praktyczną naukę administracji systemami Linux, sieciami oraz konteneryzacją.

## Zawartość projektu
* **`01-bash-scripts/`** – skrypty automatyzujące zadania administracyjne (m.in. tworzenie kopii zapasowych z walidacją błędów).
* **`02-docker-services/`** – konfiguracja usług serwerowych (Nginx, PostgreSQL) w kontenerach Docker. *(w trakcie rozbudowy)*
* **`03-network-packet-tracer/`** – symulacje sieci LAN, adresacji IP, serwera DHCP oraz DNS wykonane w Cisco Packet Tracer. *(w trakcie rozbudowy)*

## Przećwiczone zagadnienia
* Zarządzanie procesami i usługami systemowymi (`systemctl`, `journalctl`, analiza logów w `/var/log`).
* Administracja użytkownikami, grupami i uprawnieniami (`chmod`, `chown`, `sudo`).
* Diagnostyka sieciowa (`ip`, `ss`, `ping`, `dig`, `curl`).
